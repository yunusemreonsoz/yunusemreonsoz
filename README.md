## Hi, I'm Yunus Emre

**Vehicle Electronics Engineer @ BMC Otomotiv - Ankara, Türkiye**

I build LabVIEW-based test and validation systems for automotive E/E hardware.

Day to day I develop test software on PXI/PXIe platforms using Producer-Consumer and Queued Message Handler (QMH) architectures, with Functional Global Variables for modular data handling and state control. My work covers functional testing over analog/digital I/O, CAN, Ethernet and RS-232/RS-485, together with dynamic reporting and data-logging infrastructure for test results.

Currently completing an MSc in Electrical and Electronics Engineering at Sakarya University of Applied Sciences. Thesis: real-time validation of an MPC-based SEPIC DC-DC converter in a Hardware-in-the-Loop environment.

**Focus:** LabVIEW - TestStand - PXI/PXIe - NI-DAQmx - CompactRIO & LabVIEW Real-Time - HIL - CAN
